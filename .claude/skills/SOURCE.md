# Where these skills come from

The folders here are copied unchanged from the `skills/engineering` and `skills/productivity` folders of https://github.com/mattpocock/skills at commit `bbadaa631c37af594e5a05c9cefacd9956136b18` (27 November 2026), without each skill's `agents/openai.yaml`, which only Codex reads. To update them, copy the folders again from a newer commit and change the commit here.

How this repo uses them is in `CLAUDE.md` ("Agent skills") and `docs/agents/`. Do not edit the skills to fit this repo: put the repo's own rules in those files.
